# Task-4-Advanced-Analytics-Statistical-Modeling

Dataset: SampleSuperstore(4).csv
Records: 8,827
Customers: 790

## Completed
1. Descriptive statistics: mean, median, standard deviation, skewness
2. Welch t-test: Consumer vs Corporate Sales
3. Chi-square test: Region vs Category
4. 95% confidence intervals for Sales and Profit
5. Monthly time-series conversion
6. 3-month moving-average forecast
7. Trend/seasonality/residual decomposition
8. Customer RFM + StandardScaler + K-Means (4 clusters)
9. Cluster profiling and business recommendations
10. Linear Regression with 80/20 train-test split
11. R², RMSE, MAE evaluation
12. Top model features

## Key results
- Sales mean: 92.86
- Profit mean: 11.20
- t-test p-value: 0.1915
- chi-square p-value: 0.8186
- K-Means silhouette score: 0.326
- Regression R²: 0.389
- Regression RMSE: 89.99
